# Правила для агентов

Проект: хаб для беговой дорожки FitLogic T12B. План — [docs/PLAN.md](docs/PLAN.md). Язык документации и общения — русский.

## Безопасность — обязательно

- **Никогда не отправлять дорожке команды движения** (старт, скорость, наклон, запуск программы) вне режима «Тест» хаба. Режим включает только человек, когда на дорожке никого нет.
- Если режим «Тест» ещё не реализован (этапы 0–1): команды движения с PC (`bleak`) — только после явного подтверждения пользователя в чате, на каждую сессию.
- Чтение телеметрии, подписка на уведомления, чтение логов — разрешены всегда.
- Команда «стоп» разрешена всегда.

## Репозиторий публичный

- Не коммитить: сырые HCI-логи и bugreport (`protocol/raw/`), декомпилированный код FitShow, историю тренировок, IP/MAC-адреса и прочие локальные данные (`*.local.*`, `.env`).
- Не копировать код из qdomyos-zwift (GPL-3.0). Можно использовать как источник знаний о протоколе — со ссылкой.
- В `protocol/captures/` — только отфильтрованный обмен с дорожкой.

## Доступ к хабу

- ADB: `adb connect <IP-хаба>:5555` (IP — в `hub.local.json`, не в репозитории).
- Debug API хаба — см. раздел API в плане (после этапа 2).
