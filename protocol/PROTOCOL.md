# BLE-протокол FitLogic T12B (FitShow)

Статус: **не подтверждено** — заполняется на этапах 0–1 по собственным записям обмена.

## Что известно из открытых источников

По данным [qdomyos-zwift PR #4919](https://github.com/cagnulein/qdomyos-zwift/pull/4919) (для другого устройства FitShow; на T12B нужно проверить):

| Элемент | Значение |
|---|---|
| Сервис | `FFF0` |
| Уведомления (дорожка → телефон) | `FFF1` |
| Запись (телефон → дорожка) | `FFF2`, WriteWithoutResponse, если поддерживается |
| Опрос | ~2 Гц, после последовательности инициализации |

Возможна поддержка стандартного FTMS (`0x1826`) — проверить в nRF Connect.
